# MAG_TUMAN_MAG AI

Telegram Mini App starter.

## Render
- Build command: `npm install`
- Start command: `npm start`
- Health check path: `/health`

Environment variables:
- `BOT_TOKEN` — Telegram bot token (keep secret)
- `WEB_APP_URL` — public HTTPS URL of this service
- `OPENAI_API_KEY` — OpenAI API key for image generation

Image generation requires a valid API key and API billing. Video generation is not connected in this starter and needs a separate video provider/API key.
