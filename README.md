# MAG_TUMAN_MAG AI — Telegram Mini App

Стартовый проект Telegram Mini App с мобильным тёмным интерфейсом, Telegram WebApp SDK, проверкой `initData` на сервере, разделами трендов, инструментов, профиля и заданий.

## Важно о готовности
Интерфейс и серверная основа готовы. Реальная генерация изображений/видео, платежи и постоянное хранение баланса требуют подключения выбранных провайдеров и базы данных. Проект не имитирует успешную генерацию или оплату: пока API не подключён, сервер честно возвращает сообщение о необходимости настройки.

## Запуск локально
1. Установите Node.js 18+.
2. Скопируйте `.env.example` в `.env`.
3. Для локального просмотра оставьте `DEMO_MODE=true`.
4. Выполните:
   ```bash
   npm install
   npm start
   ```
5. Откройте `http://localhost:3000`.

Для Telegram нужен публичный HTTPS-адрес. Локальный localhost напрямую Telegram не откроет.

## Подключение к Telegram
1. Откройте `@BotFather` в Telegram и создайте бота командой `/newbot`.
2. Сохраните токен только в `.env` на сервере. Не отправляйте его в чат и не добавляйте в frontend.
3. Разместите приложение на HTTPS-хостинге.
4. В BotFather настройте Mini App / Web App URL на адрес приложения (меню `/mybots` → ваш бот → Bot Settings → Menu Button или Main App, если доступно).
5. Установите `DEMO_MODE=false` в production и задайте `BOT_TOKEN`.
6. Проверьте открытие Mini App из Telegram. Сервер валидирует подпись `initData`.

## Что подключить для полноценного коммерческого запуска
- AI: выбрать API для генерации изображений и видео; добавить серверные адаптеры и хранение результатов.
- Платежи: Telegram Stars (`XTR`) или поддерживаемый платёжный провайдер; подтверждать оплату только серверным webhook/update.
- База данных: PostgreSQL для пользователей, балансов, заданий, заказов и истории генераций.
- Хранилище: S3-совместимое хранилище для загруженных и созданных файлов.
- Админ-панель: управление пользователями, тарифами, заданиями, контентом и модерацией.

## Безопасность
- Никогда не включайте `DEMO_MODE=true` в публичном production.
- Не доверяйте user ID, балансу или статусу платежа из браузера.
- Проверяйте Telegram `initData` на сервере (проверка уже реализована).
- Храните секреты только в переменных окружения.
- Ограничивайте размер/тип загружаемых файлов и частоту запросов.
